# API совместных подборок

## Базовые сведения

**Базовый URL:** `http://localhost:8080/api/`.

Все маршруты требуют заголовок:

```http
Authorization: Bearer <access_token>
Content-Type: application/json
```

Токен получается существующим маршрутом `POST /auth/jwt/create/`. Внешний
маршрут API проходит через Nginx; обращаться к backend-порту напрямую не нужно.

## Роли

| Роль | Возможности |
|---|---|
| Владелец | Полностью управляет подборкой и участниками, добавляет котиков, рассматривает заявки, удаляет подборку |
| Редактор | Читает подборку, добавляет и удаляет котиков, одобряет и отклоняет заявки |
| Читатель | Только читает подборку и участников |
| Пользователь вне подборки | Может предложить собственного котика, но не читает состав или участников |

## Жизненный цикл заявки

1. Авторизованный пользователь отправляет собственного котика в `POST /proposals/`.
2. Создаётся заявка со статусом `pending`; котик не добавляется в подборку.
3. Владелец или редактор получает список заявок.
4. `approve` переводит заявку в `approved` и добавляет котика в подборку.
5. `reject` переводит заявку в `rejected` и не меняет состав подборки.
6. Рассмотренную заявку нельзя обработать повторно.

## Маршруты

| Маршрут | Методы | Доступ |
|---|---|---|
| `/api/collections/` | `GET`, `POST` | Список участника; создание — любой авторизованный |
| `/api/collections/{id}/` | `GET`, `PATCH`, `DELETE` | Чтение — участник; изменение и удаление — владелец |
| `/api/collections/{id}/members/` | `GET`, `POST` | Чтение — участник; приглашение — владелец |
| `/api/collections/{id}/members/{user_id}/` | `PATCH`, `DELETE` | Владелец |
| `/api/collections/{id}/cats/` | `POST` | Владелец или редактор; только собственный котик |
| `/api/collections/{id}/cats/{cat_id}/` | `DELETE` | Владелец или редактор |
| `/api/collections/{id}/proposals/` | `POST`, `GET` | Предложение — любой авторизованный; просмотр — владелец или редактор |
| `/api/collections/{id}/proposals/{proposal_id}/approve/` | `POST` | Владелец или редактор |
| `/api/collections/{id}/proposals/{proposal_id}/reject/` | `POST` | Владелец или редактор |

`GET /api/collections/` поддерживает `search`, `role=owner|editor|viewer` и
`page`. Размер страницы — 10.

## Примеры

Создать подборку:

```http
POST /api/collections/
```

```json
{
  "title": "Коты из приютов",
  "description": "Питомцы, которым нужен дом"
}
```

Предложить котика:

```http
POST /api/collections/12/proposals/
```

```json
{
  "cat_id": 31
}
```

Одобрить заявку:

```http
POST /api/collections/12/proposals/8/approve/
```

Ошибка при повторном добавлении котика возвращает `400 Bad Request`:

```json
{
  "cat_id": [
    "Этот котик уже добавлен в подборку."
  ]
}
```

Ошибка прав доступа возвращает `403 Forbidden`:

```json
{
  "detail": "Только владелец или редактор может рассматривать заявки."
}
```

## Проверка

Импортируйте [Postman-коллекцию](../postman/Kittygram%20Collaborative%20Collections.postman_collection.json),
задайте переменные коллекции и выполняйте запросы по порядку. Автоматические
проверки находятся в `backend/collaborations/tests.py`.
